# forgebeam

Forge numeric beam values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/forgebeam/

## Install / run

```bash
git clone https://github.com/theworker02/forgebeam.git
cd forgebeam
node src/cli.js
node --test
```
